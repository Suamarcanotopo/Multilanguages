# Japonês — Índice completo da trilha
**Variante:** Japonês padrão; escrito em kana/kanji e romaji Hepburn. **Explicação:** português brasileiro. **Público:** a partir de 14 anos.

**Progresso deste idioma:** 30/30 aulas criadas; 0 homologadas. As outras línguas não são incluídas aqui.

## Atualização sem misturar os idiomas
A fonte da verdade é cada arquivo de aula em `idiomas/japones/aulas/PST-XXX.md`, com campo `**Status:**`. Esta página é um índice gerado, nunca uma segunda cópia das aulas.

**Gerar:** `python3 scripts/build_indices.py --write` · **Verificar:** `python3 scripts/build_indices.py --check`. A aprovação linguística exige evidências humanas.
